# STORM 🌩️

STORM is a multiplayer Third-Person Shooter / Battle Royale (TPS/BR) game developed with Unity, leveraging Photon Fusion for robust networking and PlayFab for backend services and social features (Friends System).

## 🎮 Features
- **Fast-paced TPS/BR Gameplay**: Built on top of robust networking architectures.
- **Advanced Networking**: Powered by [Photon Fusion](https://doc.photonengine.com/fusion/current/getting-started/fusion-intro) for lag-free, deterministic multiplayer experiences.
- **Social System**: Integrated with [PlayFab](https://playfab.com/) for user authentication, friend lists, and presence status.
- **Scalable Architecture**: Designed with modularity in mind to support future expansions like a ghost placement/building system.

## 🛠️ Technology Stack
- **Game Engine**: Unity 3D
- **Networking**: Photon Fusion
- **Backend & Cloud Services**: Azure PlayFab

## 🚀 Getting Started

### Prerequisites
- Unity Editor (Check `ProjectVersion.txt` for the exact version)
- A PlayFab Title ID configured for the project
- Photon Fusion App ID

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MASTFAX12/STORM.git
   ```
2. Open the project in Unity.
3. Configure your PlayFab and Photon Fusion IDs in their respective settings windows.
4. Open the `Menu` scene located at `Assets/TPSBR/Scenes/Menu.unity` and hit Play!
